# Emoji images

The PNG files in this folder are from Noto Emoji (https://github.com/googlefonts/noto-emoji, `2D/png/128`), licensed under the Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).

Fetched by `scripts/sync-caption-emoji.mjs`. Captions draw them as image overlays because the subtitle renderer cannot draw colour emoji.
